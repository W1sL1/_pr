Двойное использование слова Node в конструкции typedef struct Node { ... } Node; необходимо для того, чтобы в языке C (Си) вы могли объявлять переменные этого типа без обязательного использования ключевого слова struct.Вот как это работает изнутри:Разбор конструкцииstruct Node { ... } — создает структуру с именем (тегом) Node. В чистом Си вы обязаны писать struct Node my_node; каждый раз при создании переменной.typedef ... Node; — создает короткий псевдоним (синоним) с именем Node. Благодаря этому можно писать просто Node my_node;.Зачем нужны оба имени одновременно?Внутри самой структуры есть ссылки на саму себя: struct Node *left; и struct Node *right;.На момент компиляции строк struct Node *left; короткое имя Node еще не существует (оно появится только в самом конце строки).Поэтому для указателей на дочерние элементы компилятору обязательно нужно указать полный тег: struct Node.Как это выглядит на практикеc// ОБЪЯВЛЕНИЕ
typedef struct Node { 
    int data; 
    struct Node *left;  // Тут используем старое имя, так как новое еще не создано
    struct Node *right; 
} Node;                 // Тут создаем новое короткое имя

// ИСПОЛЬЗОВАНИЕ В КОДЕ
int main() {
    struct Node old_style; // Так писать можно, но долго
    Node new_style;        // Так писать быстро и удобно благодаря typedef
}
Используйте код с осторожностью.В языке C++ (Си-плюс-плюс) это дублирование уже не нужно, там можно писать просто struct Node { ... }; и использовать слово Node без приставки struct. Но в чистом Си такая запись остается стандартом.
